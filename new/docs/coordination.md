# 轮值协调记录

## 议题
期末大作业原型的模块拆分与整合顺序

## 参与人
本人、同学 B、同学 C

## 讨论要点

1. **模块拆分粒度**：是按"页面"拆还是按"功能"拆？
   - 分歧：本人主张按功能模块（页面/交互/图表/三维），同学 B 主张按页面拆
   - 结论：按功能模块拆，便于复用作业五/六/七的代码

2. **数据衔接方式**：四个模块如何避免孤立？
   - 分歧：同学 C 建议用后端 API 统一数据，本人认为原型阶段用 localStorage + JSON 即可
   - 结论：原型用 localStorage + 静态 JSON，期末大作业再考虑后端

3. **三维场景定位**：是核心功能还是装饰？
   - 结论：作为社团视觉符号（星瀚=星海），独立页面但与主题强关联

## 结论
按"骨架→交互→图表→三维"顺序整合，每块完成即提交一次 Git。
