# 期末大作业实施计划（初稿）

## 任务分解

| 阶段 | 任务 | 产出 |
|------|------|------|
| 原型（本次） | 整合作业五/六/七，完成星瀚科技社原型 | new/ 目录全部文件 |

## 风险清单

| 风险 | 等级 | 应对 |
|------|------|------|
| 后端开发不熟练 | 高 | 先用 JSON Server 快速搭建，逐步替换 |
| 三维建模耗时 | 中 | 用基础几何体组合，不追求精细模型 |
| 时间不足 | 中 | 优先保证核心模块（活动/成员/看板），三维为进阶 |
| 跨域问题 | 低 | 同源部署，或配置 CORS |
